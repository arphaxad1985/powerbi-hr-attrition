# HR Attrition & Retention Dashboard — Power BI

A Power BI report analysing employee attrition, tenure, hiring trends,
promotion rates, and gender representation across 5 departments.

## Key Insights

1. **40% attrition despite 79-month average tenure** (~6.6 years) —
   employees stay long-term but retention is a recent challenge
2. **Balanced gender representation** — 50/50 split across all departments
3. **Declining hiring trend** — hires dropped from 3/year (2015) to
   1/year (2024), while exits remain at 4/year
4. **Strong promotion culture** — 40% promotion rate, but hasn't
   reduced attrition
5. **Stable performance** — average rating 3.4/5

## Recommendation

Investigate root causes of attrition despite high tenure and promotion
rates. Consider exit interviews and department-level retention strategies,
especially given the declining hire rate.
